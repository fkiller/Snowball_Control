# Snowball North Star

Snowball은 **inter-Harness 로컬 제어 인터페이스**다. 사용자 컴퓨터에서 실행 중인 AI 하네스를 로컬 미들웨어와 MK20 데스크 터미널로 즉시 제어한다. PC가 작업공간과 네이티브 프로세스를 소유하고 MK20은 물리 입출력을 담당한다. 용어의 의미와 제품 철학은 [중앙 아키텍처 문서](ARCHITECTURE.ko.md#제품-철학-inter-harness-로컬-제어)에 정의한다.

## 불변 원칙

- **Local first:** 클라우드 제어 플레인을 필수 전제로 두지 않는다. 이미 설치한 로컬 구성의 제어는 인터넷 없이 동작해야 한다. 클라우드 모델 추론과 최초 다운로드의 네트워크 필요성은 구분한다.
- **실제 동작:** 승인, 세션 생성, 모델/effort 변경, 중단과 STT는 실제 하네스·기기 결과에 연결한다. 가짜 응답이나 대기 후 성공으로 미완성 기능을 숨기지 않는다.
- **동적 원천:** 모델, 지원 effort, 프로젝트와 세션은 CLI·캐시·인덱스·DB에서 발견한다. 실패/빈 상태에 개인 프로젝트나 정적 목록을 대신 만들지 않는다.
- **로컬 UI:** Supervisor는 루프백 전용이며 로그인/PIN 없이 사용한다. 기기 페어링은 별도 경계다.
- **권한 분리:** 플러그인의 권한을 제한하되, 승인된 호스트의 실제 dispatch와 observer를 막는 것으로 격리를 대신하지 않는다.

현재 구현, Preview 제한, MK20 키·화면 계약, 설치 버전, 배포와 검증 상태는 [docs/ARCHITECTURE.md](ARCHITECTURE.md)에서만 관리한다. 이 문서는 제품의 방향을 정의하며 모든 목표의 현재 달성을 주장하지 않는다.
